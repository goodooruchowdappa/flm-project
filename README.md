# Companies Directory

Live Demo: [https://6903d3657154a117af1538ec--whimsical-creponne-58ac1a.netlify.app/]


## Features
- Responsive table/cards
- Search + multi-filter (industry, location)
- Sorting & pagination
- Loading/error states
- Centralized API with Axios

## Setup
```bash
npm install
npm run dev
or
npm start
```

## Tech Stack
- React, MUI, Redux Toolkit, Axios, JSON Server
